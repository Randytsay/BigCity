# Big City Smart Energy Operations Demo

遠東巨城 EMS + Analytics 未來介面概念 Demo。

## V0.1 定位

這不是既有 BMS / WebCTRL 的替代品，也不是本案 AI 自動控制承諾。

本 Demo 用來呈現上層「智慧能源營運總管」可能提供的價值：

- 跨場域：巨城本館、創藝大樓、威秀影城
- 把既有 BMS 數值轉成可理解的營運洞察
- 顯示現象、證據、可能原因與建議操作／觀察
- 整合冷源、水側、AHU、舒適度、效率與節能績效
- 本案採 Advisory Mode：提供分析與建議，不直接下控設備
- 自動最佳化控制列為未來擴充方向

## 使用方式

直接開啟 `index.html` 即可。

目前頁面數值均為情境模擬資料，僅供 UI / Demo 概念展示，不作為正式計畫書、驗收、節能量或設備性能依據。
